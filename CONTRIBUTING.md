# Contributing

Thanks for helping CSIRTs find good resources!

1. Find the right section through the [Contents](README.md#contents). Topic pages live in [`lists/`](lists/).
2. Add one item per line using this format:
   `- [Name](https://link): Short description.`
3. Search the README first to avoid duplicates.
4. Code and samples go in [`pocs/`](pocs/), [`scripts/`](scripts/) or [`intel/`](intel/). Add a row to that folder's `README.md` too.
5. Open a pull request. CI lints the Markdown and checks the links in your change.
